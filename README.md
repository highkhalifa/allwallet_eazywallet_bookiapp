# Wallet

A personal spending tracker, installed to the iPhone home screen.

Live at https://highkhalifa.github.io/allwallet_eazywallet_bookiapp/

- `app/` holds the source (a React + Vite project). See `app/README.md`.
- `index.html` and `sw.js` at the root are the built app that GitHub Pages
  serves. They're generated from `app/`, so don't edit them by hand.
